FARM TO HOME

Farm to Home is a full-stack web application designed to connect farmers directly with consumers. The platform allows farmers to list their products and enables users to browse and purchase fresh produce without intermediaries.

*Overview
This project focuses on simplifying the agricultural supply chain by providing a direct connection between farmers and customers. It ensures better pricing for farmers and access to fresh products for consumers through a simple and efficient web interface.

*Features
Product listing and management for farmers
Browse and purchase agricultural products
Order handling and basic data management
Simple and user-friendly interface
Direct interaction between farmers and consumers

*Technologies Used
HTML
CSS
JavaScript
Java (JSP for backend logic)

*Working
Farmers can add product details through the system. Users can view available products and place orders. The backend processes user requests and manages data related to products and orders.

*Objective
To build a transparent system that reduces dependency on middlemen and improves accessibility to fresh agricultural products.

*Team Contribution
This project was developed as part of a group. Responsibilities were shared across frontend design, backend development, and testing.
